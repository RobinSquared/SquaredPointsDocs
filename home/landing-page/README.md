# SquaredPoints Docs

## Stream progression, squared

### Every game. One score.

Earn Squared Points through the RobinSquared Twitch channel and Discord server. Join stream games and community activities, then climb the leaderboard each season.

{% hint style="success" %}
**Season 01 is live.** Your next eligible catch, stream interaction, or Discord activity can move the board.
{% endhint %}

### A score that stays with you

Eligible Twitch and Discord activity build one shared SP account. Your available balance pays for perks. Your lifetime level and season score stay intact.

{% hint style="info" %}
The first eligible activity creates your private Squared Points profile.
{% endhint %}
