# Getting help

## Getting help

Join the [Discord community](https://discord.gg/robinsquared) to ask questions or report an issue.

### Include these details

A complete request helps others understand the problem quickly.

* Describe what you tried and what happened.
* Include the expected result and the actual result.
* Add screenshots or exact error messages when available.

### Account-specific requests

Include your User ID only when a team member asks for it. Follow [getting-your-user-id.md](getting-your-user-id.md "mention") to find it.

{% hint style="warning" %}
Never share your password, access token, or recovery codes in a support request.
{% endhint %}
